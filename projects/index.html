Baconometer — The Interactive Film Network Exploration Tool

Use The Baconometer at baconometer.foobarcat.com.

The Baconometer is a tool based upon Six Degrees of Kevin Bacon. It allows a user to explore the degrees of separation between any two actors, discovering the shortest path between them via shared film appearances. Built to explore graph-based systems, experiment with AI-assisted development, and investigate network structure.
